Data Quality Corrections Applied
  • Broken goal-total column — total_goals_team1/2 returned 0 for most matches despite real scores existing in fulltime_score columns. All analysis re-pointed to the correct columns.
  • Duplicate country names — merged inconsistent entries (e.g. "USA" / "United States", "Ivory Coast" / mis-encoded French name).
  • Character encoding errors — corrected UTF-8/Latin-1 mis-encoding affecting accented country names.
  • Inconsistent stage labels — standardized three different labels for the same third-place match category.
